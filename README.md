# Сменщик

Ночная смена в конторе «Глооми-Корп»: звонки, кофе, пробки и стук в дверь.
HTML/CSS/JS, без сборки и без своего сервера.

## Как играть
- Меню → «Одиночная смена» или «Создать лобби».
- В мультиплеере хост получает 5-символьный код лобби; друзья вводят его в меню.
- Смена идёт с 00:00 до 08:00 (реально ~7 минут). Задания появляются на столе:
  их нужно «взять» и правильно обработать. В начале смены приходит случайный
  «Приказ смены» (кодовое слово, договор и скидка, рецепт кофе, нужный рубильник,
  время закрытой двери) — он свой на каждую смену, ответы в кнопках перемешаны.
- Правильное действие — баллы. Ошибка или пропущенное задание — жалоба.
- Три жалобы — увольнение. Дожили до 08:00 — смена пройдена.
- В мультиплеере (2+ игроков) звонков и событий приходит вдвое больше,
  а чат лобби и смены шифруется AES-GCM: ключ выводится из кода лобби,
  брокер видит только шифротекст.

## Технологии
- Мультиплеер: MQTT через публичные брокеры (broker.emqx.io, запасной
  test.mosquitto.org) по WebSocket — библиотека `vendor/mqtt.min.js`
  (MQTT.js 5.16.1), без PeerJS и без своего сервера. Код лобби —
  уникальные топики `smenschik-v2/<код>/…`; состояние хоста публикуется
  как retained-сообщение, у клиентов — Last Will для выхода.
- Хост-авторитетная модель: правильные ответы не отправляются клиентам
  (anti-cheat: sanitation в `publicState()`).

## Файлы
- `index.html` — экраны: меню, лобби, игра, итоги + справочник.
- `style.css` — ночная тема.
- `game.js` — сетевой код, логика смены, отрисовка.
